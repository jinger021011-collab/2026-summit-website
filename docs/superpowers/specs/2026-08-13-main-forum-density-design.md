# 桌面端主论坛紧凑布局设计

## 目标

在 1440×900 桌面视口中，将“主论坛”模块滚动到页面顶部后，主论坛标题、表头和全部 8 条议程完整显示；在 1920×1080 下同样完整可读且无横向滚动。

## 设计

- 在桌面议程中增加独立的 `.main-forum` 容器，只包裹“主论坛”标题与主论坛表格。
- 主论坛容器使用 `padding: 28px 0 36px`，标题使用 30px 字号和 20px 下边距。
- 主论坛表头使用 `14px 20px` 内边距、16px 字号、1.3 行高。
- 主论坛正文使用 `11px 20px` 内边距、垂直居中和 1.35 行高；时间 16px、议题 17px/600、嘉宾姓名 16px/600、单位职务 14px。
- 英文长议题允许自然换行，不截断、不缩放。
- 保留现有 1280px 容器、160px／50%／剩余宽度三列结构。
- 所有规则限定在桌面端 `.main-forum`，下午分论坛和移动端时间轴不改变。

## 验收

- 1440×900 和 1920×1080 下，主论坛标题、表头及 8 条议程均在一屏内完整显示。
- 主论坛最后一行未被遮挡，文字清晰，无横向滚动。
- 表格行和单元格没有固定高度或最小高度。
- 移动端继续使用现有时间轴卡片。
