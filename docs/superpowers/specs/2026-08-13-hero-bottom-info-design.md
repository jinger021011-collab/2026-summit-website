# 首屏底部会议信息栏设计

## 目标

首屏直接保留现有 1920×1080 大会头图中的大会名称、DB × AI、AI 字母和彩色玻璃装置，将日期、地点、参会形式和报名按钮统一放入底部信息栏，避免遮挡主体。

## 桌面端设计

- 首屏使用现有 1920×1080 素材作为视觉层，使用 `object-fit: cover` 和居中定位，不拉伸原图。
- 页面不再输出可见的第二组主题或大会名称，仅保留 `.sr-only` 的语义化 `h1`。
- 日期、地点、参会形式和“立即报名”组成底部横向信息栏；信息栏最大宽度 1280px，位于 AI 装置下方的地面倒影区域。
- 信息栏使用 58% 透明深蓝背景、8px 背景模糊、浅蓝边框和分隔线，使地面倒影可见且文字清晰。
- 保留现有报名链接地址、位置追踪参数和可访问标题结构。

## 移动端设计

- 767px 及以下采用上下结构。
- 上方以 16:9 完整展示原头图。
- 下方独立深蓝信息区使用 HTML 输出日期、地点、参会形式和报名按钮。
- 信息区不覆盖视觉图片，页面宽度自适应且无横向滚动。

## 验收

- 1280px、1440px、1920px 桌面宽度下，只有一组可见主题与大会名称，信息栏不遮挡 AI 主体，无内容溢出。
- 移动端为上图下文，不使用大面积文字叠加图片。
- 原图不拉伸；报名按钮保持可用；核心文案仍由 HTML 输出。
