# Timecho 官方页脚设计

## 范围

只替换活动页最下方的简化页脚，并调整移动端固定报名栏在页脚进入视口后的显示状态。头图、议程、嘉宾、合作伙伴、参会须知和大会报名引导区均不修改。

## 参考实现

以 `https://www.timecho.com/activity/2026-Summit` 当前页面的官网页脚为内容与视觉参考；按后续确认删除“立即体验国产工业时序数据库”推广区。页脚使用 `#131926`，桌面内容宽度约 1000–1180px，导航、联系与合规信息之间使用细分隔线。

官网在 768px 和 390px 下存在横向溢出，本项目不复制该缺陷，而是在保持品牌视觉的前提下实现无横向滚动的响应式布局。

## 内容与交互

1. 不渲染 TimechoDB 产品推广区、主副文案、四项特点及两个行动入口。
2. “联系我们”使用可访问按钮，滚动并聚焦到页脚官方联系方式区域，避免空链接和虚假地址。
3. 页脚展示产品、资源和关于我们三组导航，所有真实链接使用官网当前地址并在新标签页打开。
4. Footer 上半部分不展示 Timecho Logo，也不常驻展示二维码；产品、资源、关于我们三组导航占据左侧和中间区域。
5. 微信、Twitter/X、GitHub 三个深灰色圆形 SVG 控件位于桌面端最右侧、移动端导航下方。微信悬停、聚焦或点击时显示本地 `assets/timecho-wechat-qr.png` 二维码，Twitter 与 GitHub 使用官网已确认链接。
6. 联系区展示指定地址和电话；合规区展示固定 2026 版权、Apache 商标声明、隐私协议和工信部备案链接。删除 Powered by Halo。

## 响应式与可访问性

- 桌面端为品牌列加三组导航列，联系与合规信息横向分区。
- 768px 平板重排为两列，不溢出。
- 390px 移动端三组导航使用原生 `details/summary` 折叠结构，链接触控高度至少 44px，联系与合规信息自然换行。
- 所有外链使用 `target="_blank" rel="noopener noreferrer"`，链接与按钮提供 hover、focus-visible 和 active 状态。
- Footer 进入视口后隐藏移动端固定报名栏，防止遮挡。

## 验收

自动测试覆盖内容、链接、安全属性、无空 href、联系按钮行为和 Halo 文案缺失；构建后在 1440、1920、768、390 四种宽度检查无横向滚动，并输出 1440 桌面与 390 移动端截图。
