## 1. 项目说明

本项目为“2026 时序数据技术创新大会”单页活动官网，主要用于大会信息展示、议程查询、嘉宾及合作伙伴展示、参会指引和报名转化。

页面需同时适配桌面端和移动端。所有重要信息必须以 HTML 文本输出，不得仅依赖图片中的文字，以保证搜索引擎收录、无障碍访问和后期内容维护。

## 2. 开发原则

1. 优先沿用现有项目的技术栈、目录结构和组件规范；如果是全新项目，默认使用 React、Vite 和 TypeScript。
2. 议程、嘉宾、合作伙伴及参会信息采用集中式数据配置，避免在多个组件中重复硬编码。
3. 桌面端与移动端均不得出现页面级横向滚动。
4. 外部链接使用新标签页打开，并增加 `rel="noopener noreferrer"`。
5. 首屏主视觉优先加载；首屏以下图片使用懒加载，并为图片预留尺寸，减少布局偏移。
6. 所有交互控件应支持键盘操作，并具备清晰的悬停、聚焦、按下和禁用状态。
7. 尊重系统的“减少动态效果”偏好；在 `prefers-reduced-motion: reduce` 下关闭非必要动效和平滑滚动。
8. 不得自行补写未确认的嘉宾、议题、合作伙伴或大会规则。待确认内容按本文约定隐藏或显示占位提示。

## 3. 素材目录约定

```text
assets/
├── hero/                 # 桌面端与移动端头图
├── speakers/             # 嘉宾照片，使用数字命名
├── logos/                # 主办方、合作伙伴、媒体 Logo
└── venue/                # 场地平面图等会场图片
```

### 3.1 素材使用要求

- 头图应分别提供桌面端和移动端版本，建议命名为 `hero-desktop.*`、`hero-mobile.*`。
- 嘉宾照片放置于 `assets/speakers/`，按照嘉宾序号命名为 `1.jpg`、`2.jpg`、`3.jpg`……
- 嘉宾照片统一采用 4:5 或 1:1 比例，主体居中，背景尽量一致；不得直接放大低清图片。
- Logo 放置于 `assets/logos/`，优先使用 SVG 或透明背景 PNG。
- 场地平面图建议命名为 `场地平面图.jpg`，放置于 `assets/venue/`。
- 所有图片均需设置有意义的 `alt` 文本；纯装饰图片使用空 `alt`。

## 4. 页面功能需求

### 4.1 全局导航（F-01）

#### 桌面端

- 左侧展示 Timecho Logo 或大会标识，点击后返回页面顶部。
- 导航项依次为：大会简介、大会议程、嘉宾介绍、合作伙伴、参会须知。
- 右侧设置主要行动按钮“立即报名”。
- 页面向下滚动后导航栏吸顶，并保持清晰可读的背景和层级。
- 当前浏览模块所对应的导航项显示高亮状态。
- 点击导航项后滚动至对应模块，同时预留吸顶导航高度，避免模块标题被遮挡。
- 系统开启“减少动态效果”时，导航跳转不使用平滑滚动。

#### 移动端

- 使用汉堡菜单展示导航项。
- 菜单展开后锁定页面背景，避免背景继续滚动。
- 选择任一模块后，菜单自动关闭并跳转至对应位置。
- 菜单支持遮罩点击关闭、Esc 关闭和键盘焦点管理。

#### 报名跳转与统计

- 导航栏“立即报名”在新标签页打开报名页。
- 点击时上报统一事件 `registration_click`，参数为 `position=navigation`。
- 如果项目尚未接入统计工具，只保留统一的事件调用接口，不额外引入第三方统计依赖。

### 4.2 大会头图（F-02）

首屏需在无需滚动的情况下呈现大会主题、正式名称、日期、地点、参会形式和主报名按钮。

视觉延续“DB × AI”彩色折射字、蓝色空间和玻璃光效，但大会正文信息不得依赖背景图中的文字。

| 元素 | 内容要求 | 交互与状态 |
| --- | --- | --- |
| 主视觉 | DB × AI 主题图形；提供桌面端和移动端裁切版本 | 不同断点下保持主体可见，不拉伸、不变形 |
| 核心文案 | 大会名称、主题、日期、酒店、城市、线下会议＋线上直播 | 使用 HTML 文本输出，保证可搜索和可访问 |
| 主按钮 | 立即报名 | 新标签页打开报名页；上报 `position=hero` |
| 辅助提示 | 向下了解大会 | 点击后滚动至大会简介；减少动态效果模式下取消循环动画 |

### 4.7 参会信息（F-08）

该模块使用三个可切换标签：**参会须知、交通指南、场地平面图**。

#### 4.7.1 标签交互

- 默认展示“参会须知”。
- 当前标签具有清晰的选中状态。
- 支持鼠标、触摸和键盘方向键切换，并提供正确的 `tablist`、`tab` 和 `tabpanel` 语义。
- 切换内容时避免明显高度跳动；减少动态效果模式下取消切换动画。

**现场签到**

- 选择线下参会的嘉宾，请提前完成线上报名，并于大会当天提前到达会场。

- 报名成功后将通过短信发送相关通知，请确保报名时填写的手机号准确并保持畅通。
- 大会议程、演讲嘉宾和演讲主题可能根据实际情况调整，请以大会当天公布的信息为准。
- 会议期间请将手机调至静音或振动状态，共同维护会场秩序。
- 请妥善保管电脑、手机及其他贵重物品。
